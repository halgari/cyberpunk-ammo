# v1 Calibers Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** All 13 calibers at Common and Uncommon, with per-caliber profiles (stats on the guns, ammo weight, price, availability), using the slice's machinery.

**Architecture:** Each caliber is one YAML file (`src/tweaks/AmmoOverhaul/<family>_<caliber>.yaml`) holding its feed slot, rounds, selectors, profile group and `AmmoOverhaul.<Caliber>.*` flats, listed in `AmmoOverhaul.calibers`. The startup tweak (`AmmoFeedTweak.reds`) already sets each matched gun's ammo and adds its feed slot; it now also appends the caliber's profile `StatModifierGroup` to the gun's `statModifierGroups`, and matches guns by record ID as well as tag. Vendors, loot and NPC code is unchanged; it works off the caliber list.

**Tech Stack:** TweakXL YAML, redscript, Codeware localization, CET Lua checks (`tools/linux/cet.sh`), WolvenKit icon build (`tools/icons/build.sh`), OpenAI image API for icon art.

**Spec:** `docs/superpowers/specs/2026-10-28-v1-calibers-design.md`

## Global Constraints

- Names: one load keeps one slang name across calibers, caliber as prefix (`.45 Mushrooms`, `Heavy Sleevers`, `20mm Dumbfires`); shotgun loads have their own names. The magnum group is `12mm`; `.45` stays `.45`.
- 4-gauge: Buckshot is Common; the Slug is Uncommon only. 4ga Slugs do not pierce cover.
- Enemy loadouts are not changed. NPCs get only the ammo for the guns they already carry.
- Uncommon effects (same in every caliber): Mushrooms damage ×1.2, pen −0.5; Sleevers charge time ×0.7, damage ×0.95; Dumbfires damage ×1.25, `SmartGunHitProbability` ×0.
- Profiles, damage / pen / recoil / range / ammo weight / price (spec table, verbatim): 9mm 1.00/0/1.00/1.00/1×/1×; .45 1.10/−0.15/1.10/1.00/1.5×/1.2×; 12mm 1.15/+0.10/1.35/1.00/2×/1.6×; 5.56 1.00/+0.15/1.00/1.00/1×/1×; 7.62 1.05/+0.25/1.20/1.10/1.5×/1.3×; 12.7 1.00/+0.40/1.25/1.00/2.5×/2×; 12-gauge 1.00/−0.25/1.00/0.75/1×/1×; 4-gauge 1.00/−0.25/1.30/1.00/2.5×/2×; 5mm light rail 1.00/0/1.00/1.00/1×/1×; heavy rail 1.00/+0.20/1.20/1.00/2×/1.5×; 10mm smart 1.00/−0.10/1.00/1.00/1×/1×; 20mm cluster 1.00/−0.20/1.00/1.00/1.5×/1.3×; 25mm dart 1.00/+0.10/1.00/1.00/3×/2.5×.
- Damage = `DamagePerHit` Multiplier; pen = `CanWeaponIgnoreArmor` Additive; recoil = `RecoilKickMin` and `RecoilKickMax` Multiplier; range = `EffectiveRange` Multiplier. Ammo weight is per round relative to 9mm Ball's 0.06; price is a `BaseStats.Price` Multiplier on the round's `buyPrice` and `sellPrice`.
- Shares (`lootWeight`): handgun ammo → 9mm 0.40, .45 0.20, 12mm 0.10, 5mm rail 0.15, 10mm smart 0.15; rifle ammo → 5.56 0.65, 7.62 0.35; sniper ammo → 12.7 0.60, heavy rail 0.30, 25mm 0.10; shotgun ammo → 12ga 0.70, 4ga 0.10, 20mm 0.20.
- The four game ammo items are the Common of 9mm, 5.56, 12.7 and 12-gauge (renamed in place, as `Ammo.HandgunAmmo` is now).
- Item text: slang or technical names, short plain gun-counter descriptions, no invented lore, run anti-ai-writing; the user signs off before it ships.
- Icons: square 1024×1024, single-round reference then box shot (`docs/TESTING.md` "Icons").
- All Windows tools run on GE-Proton in the tools prefix, never system wine or the game's prefix. Shut the game down when not using it.

## Review Focus

1. **Guns already in a save** (spawned before this build) must get the caliber profile and feed slot, not only freshly created guns. Pinned in Task 2 (the dev save's existing Unity / kit guns).
2. **Iconic variants** of each family (e.g. Nue "La Chingona Dorada", Overture "Crash") must get the slot and profile through their family tag. Pinned in Task 2–5 record checks: one iconic per caliber where the family has one.
3. **A gun matched by two calibers** (a record carrying two family tags, e.g. a Sidewinder that also carries a Copperhead tag) would get two feed slots and two profiles. Pinned in Task 4: every weapon record matches at most one caliber.
4. **Vendors already marked split in a slice-era save** never split their rifle, sniper or shotgun ammo until a restock. Expected behavior: a restock splits them. Pinned in Task 6 (`DebugRestock` on a marked gun shop splits rifle ammo).
5. **A gun dropped by an NPC of a new caliber** must load that caliber's ammo and carry its profile when the player picks it up. Pinned in Task 7.
